# Contributing

This repository prefers evidence over doctrine.

A useful contribution is one of:

- a reproducible experiment;
- a counterexample;
- a tighter measurement;
- a design pattern with explicit trade-offs;
- a failed hypothesis documented clearly.

## Experiment rules

When adding an experiment:

1. State the question before the expected result.
2. Keep prompts and model settings visible.
3. Preserve failed runs.
4. Separate correctness from speed.
5. Do not collapse metrics into a weighted score.
6. Document confounders and limitations.
7. Prefer several independent runs over a single demo.

## Writing rules

Write plainly. Avoid turning tentative evidence into universal claims. If a result is exploratory, call it exploratory.
