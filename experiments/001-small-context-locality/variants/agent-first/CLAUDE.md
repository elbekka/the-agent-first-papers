# Repository

This is a .NET console calculator organized around capability-local context.

## Commands

Build:

```bash
dotnet build
```

Test:

```bash
dotnet test
```

## Completion criteria

- The solution builds.
- All tests pass.
- Existing console behavior is preserved unless the task says otherwise.
- Do not introduce a new project for a feature. Capability boundaries are contextual, not compilation boundaries.
